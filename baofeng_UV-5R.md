## Раздел 1. Инструкция по пользованию Baofeng UV-5R

### Органы управления

| Элемент | Назначение |
|---------|------------|
| **Верхняя ручка (Knob)** | Включение/выключение питания, регулировка громкости принимаемого сигнала |
| **PTT (Push-To-Talk)** | Кнопка передачи: нажать и удерживать для передачи голоса, отпустить для перехода в режим приёма |
| **MON (Monitor)** | Короткое нажатие — включение/выключение фонарика. Долгое удержание — мониторинг частоты (отключает шумоподавитель, чтобы услышать слабые сигналы) |
| **CALL** | Короткое нажатие — переключение в режим FM-радио (приём радиостанций 65–108 МГц). Долгое удержание — отправка вызывного тона 1750 Гц (используется для активации некоторых радиолюбительских репитеров) |
| **VFO/MR** | Переключение между режимом ручного ввода частоты (VFO) и режимом сохранённых каналов (MR) |
| **A/B** | Переключение между верхней (A) и нижней (B) строками частот на дисплее — позволяет работать с двумя частотами одновременно |
| **BAND** | Переключение между диапазонами VHF (136–174 МГц) и UHF (400–520 МГц) |
| **MENU** | Вход в меню настроек и подтверждение выбранного параметра |
| **EXIT** | Выход из меню без сохранения изменений |
| **▲/▼** | Навигация по пунктам меню, переключение частот или каналов вверх/вниз |
| **Цифровые кнопки (0-9)** | Ввод частоты с клавиатуры или быстрый переход к пункту меню по его номеру |

### Работа с меню

1. Нажать **MENU** для входа в меню
2. Кнопками **▲/▼** или цифровыми кнопками перейти к нужному пункту
3. Нажать **MENU** для выбора настройки
4. Кнопками **▲/▼** изменить значение
5. Нажать **MENU** для сохранения
6. Нажать **EXIT** для выхода из меню

### Основные пункты меню

| № | Название | Назначение | Значения |
|---|----------|------------|----------|
| **0** | **SQL** | Уровень шумоподавителя. Чем выше значение, тем более сильный сигнал нужен для открытия динамика | 0 (полностью открыт, слышен шум) — 9 (максимально зажат, пропускает только сильные сигналы) |
| **1** | **STEP** | Шаг перестройки частоты при вращении ручки | 2.5 / 5 / 6.25 / 10 / 12.5 / 25 кГц |
| **2** | **TXP** | Мощность передатчика | HIGH (5 Вт) / LOW (1 Вт) |
| **3** | **SAVE** | Режим экономии батареи (периодическое отключение приёма) | OFF / 1-4 (чем выше число, тем экономичнее) |
| **4** | **VOX** | Голосовое включение передачи (без нажатия PTT) | OFF / 0-10 (чувствительность срабатывания) |
| **5** | **WN** | Ширина полосы модуляции | WIDE (25 кГц) / NARR (12.5 кГц) |
| **6** | **ABR** | Время подсветки экрана после нажатия кнопки | OFF / 1-5 секунд |
| **7** | **TDR** | Режим поочерёдного сканирования двух частот (верхней и нижней строки) | OFF / ON |
| **8** | **BEEP** | Звук нажатия клавиш | OFF / ON |
| **9** | **TOT** | Ограничение времени непрерывной передачи (защита от перегрева) | 15-600 секунд (шаг 15) |
| **10** | **R-DCS** | Цифровой субтон (DCS) на приём — рация открывает динамик только при совпадении кода | 000-777 (восьмеричные коды) |
| **11** | **R-CTCS** | Аналоговый субтон (CTCSS) на приём — рация открывает динамик только при совпадении тона | 67.0–254.1 Гц |
| **12** | **T-DCS** | Цифровой субтон (DCS) на передачу — рация добавляет код в передаваемый сигнал | 000-777 (восьмеричные коды) |
| **13** | **T-CTCS** | Аналоговый субтон (CTCSS) на передачу — рация добавляет неслышимый тон в передаваемый сигнал | 67.0–254.1 Гц |
| **14** | **VOICE** | Голосовое подтверждение нажатий кнопок (китайский/английский) | OFF / ENG / CHN |
| **15** | **ANNI** | Режим отображения частоты или имени канала | FREQ / NAME |
| **25** | **SFT-D** | Направление смещения частоты для работы с репитером | OFF / + / — |
| **26** | **OFFSET** | Величина смещения частоты для репитера | 00.000–69.990 МГц |

### Технические характеристики

| Параметр | Значение |
|----------|----------|
| **VHF** | 136–174 МГц (приём и передача) |
| **UHF** | 400–520 МГц (приём и передача) |
| **FM-радио** | 65–108 МГц (только приём) |
| **Мощность** | 5 Вт (HIGH) / 1 Вт (LOW) |
| **Количество каналов памяти** | 128 |
| **Модуляция** | FM (частотная модуляция) |

### Настройка для работы с репитером

Для работы через репитер (ретранслятор) необходимо настроить три параметра:

1. **SFT-D (пункт меню 25)** — направление смещения: `+` (передача выше приёма) или `—` (передача ниже приёма)
2. **OFFSET (пункт меню 26)** — величина смещения (обычно 0.6 МГц для VHF или 5 МГц для UHF)
3. **T-CTCS (пункт меню 13)** — тон доступа к репитеру (если требуется)

**Пример:** репитер принимает на 145.350 МГц, передаёт на 145.950 МГц. На рации выставляется частота приёма **145.350**, SFT-D = `+`, OFFSET = `0.600`. При нажатии PTT рация автоматически переключается на передачу 145.950 МГц.

| **TETRA (цифровая)** | 380–400, 410–430, 450–470 МГц | Цифровой стандарт — UV-5R не декодирует, слышен только шум |
| **DMR (цифровая)** | 145/438 МГц (радиолюбительские) | Цифровой стандарт — UV-5R не декодирует |
| **РЖД** | Различные УКВ-частоты | Служебная связь железной дороги |
| **Такси / Охрана** | Различные УКВ-частоты | Частоты могут меняться, многие используют цифровые системы |


## Список сокращений (с полными расшифровками)

| Сокращение | Полное название | Что это |
|------------|------------------|---------|
| **AM** | Amplitude Modulation (амплитудная модуляция) | Вид модуляции, при котором информация передаётся изменением амплитуды несущей частоты. Используется в авиационной связи |
| **APRS** | Automatic Packet Reporting System (автоматическая пакетная система передачи данных) | Система для передачи цифровых данных (координаты, метеоинформация, сообщения) радиолюбителями |
| **ATIS** | Automatic Terminal Information Service (автоматическая терминальная информационная служба) | Автоматическая передача информации о погоде и состоянии аэропорта для пилотов |
| **CTCSS** | Continuous Tone-Coded Squelch System (система шумоподавления с непрерывным тональным кодированием) | Неслышимый низкочастотный тон (67–254 Гц), добавляемый в передачу. Рация открывает динамик только при совпадении тона, что позволяет не слышать чужие переговоры на той же частоте |
| **DCS** | Digital Coded Squelch (цифровое кодированное шумоподавление) | Цифровой аналог CTCSS — вместо тона используется цифровой код (000–777). Выполняет ту же функцию — фильтрацию чужих сигналов |
| **DMR** | Digital Mobile Radio (цифровая подвижная радиосвязь) | Европейский стандарт цифровой радиосвязи. Позволяет передавать голос в цифровом виде, поддерживает два независимых канала (слота) на одной частоте |
| **D-Star** | Digital Smart Technologies for Amateur Radio (цифровые интеллектуальные технологии для радиолюбителей) | Цифровой стандарт радиолюбительской связи, разработанный JARL (Японская радиолюбительская лига). Поддерживает голос и данные |
| **FM** | Frequency Modulation (частотная модуляция) | Вид модуляции, при котором информация передаётся изменением частоты несущего сигнала. Основной режим работы UV-5R |
| **LPD** | Low Power Device (маломощное устройство) | Безлицензионный диапазон 433.075–434.775 МГц в России. 69 каналов, мощность до 10 мВт |
| **PMR** | Private Mobile Radio (личная мобильная радиостанция) | Безлицензионный европейский диапазон 446 МГц. 8 каналов, мощность до 0.5 Вт |
| **PTT** | Push-To-Talk (нажми-чтобы-говорить) | Кнопка на рации, которую нужно нажать и удерживать для передачи голоса |
| **RX** | Reception (приём) | Частота, на которой рация принимает сигнал |
| **SSB** | Single Side Band (однополосная модуляция) | Вид модуляции, при котором передаётся только одна боковая полоса частот (без несущей). Экономит мощность и полосу, используется для дальних связей |
| **TETRA** | Terrestrial Trunked Radio (наземная транкинговая радиосвязь) | Европейский стандарт цифровой профессиональной радиосвязи. Используется силовыми ведомствами, РЖД, крупными компаниями |
| **TX** | Transmission (передача) | Частота, на которой рация передаёт сигнал |
| **UHF** | Ultra High Frequency (ультравысокие частоты) | Диапазон 300–3000 МГц. В UV-5R доступен поддиапазон 400–520 МГц |
| **VHF** | Very High Frequency (очень высокие частоты) | Диапазон 30–300 МГц. В UV-5R доступен поддиапазон 136–174 МГц |
| **VFO** | Variable Frequency Oscillator (режим переменной частоты) | Режим ручного ввода частоты с клавиатуры или вращением ручки |
| **VFR** | Visual Flight Rules (правила визуальных полётов) | Полёты, при которых пилот ориентируется визуально, а не по приборам |
